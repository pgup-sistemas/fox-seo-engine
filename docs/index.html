7. Como implementar — Passo a passo

1

Criar as LPs no CMS

Use a URL sugerida na tabela da Seção 6. Cole o Title SEO e a Meta Description já prontos. Publique o conteúdo.

2

Schema por tipo de página

Unidades: Seção 1 (AutoRepair) + Seção 2 (FAQPage) no <head>. Blog: Seção 3 (Article). Pneus/Peças: Seção 4 (Product). Serviços: Seção 5 (Service).

3

Inserir como JSON-LD

Cole cada schema como bloco separado: <script type="application/ld+json">...</script> dentro do <head>. Uma mesma página pode ter múltiplos blocos (ex.: AutoRepair + FAQPage).

4

Validar no Google

search.google.com/test/rich-results para AutoRepair e Product. validator.schema.org para todos os tipos. FAQPage não gera rich result (normal desde 2026) mas valida sintaticamente.

5

Pedir reindexação

No Google Search Console, use Inspecionar URL → Solicitar indexação para as páginas novas ou editadas. O IndexNow (Bing) é feito automaticamente pelo pipeline a cada execução.

Indicadores Principais (KPIs)

Share of Voice

Percentual das buscas locais monitoradas em que a Fox aparece no Top 10 do Google. É o termômetro geral da visibilidade regional — um número resume o impacto de todas as ações de SEO.

≥ 60%Liderança regional consolidada
30–60%Crescimento ativo — priorizar criação de LPs
< 30%Crítico — concorrentes dominam as buscas
Ação recomendadaAprovar a criação das landing pages do plano de expansão. Cada LP publicada aumenta o SOV em ~0,5–1 ponto percentual.

Cobertura Local

% das combinações cidade × serviço que já possuem página dedicada no site. Uma cobertura baixa significa oportunidades de tráfego orgânico não aproveitadas.

≥ 70%Presença digital bem distribuída
30–70%Expansão em andamento
< 30%Alta perda de tráfego potencial
Ação recomendadaConsultar a tabela "Plano de Expansão" para ver quais combinações estão ausentes por cidade e priorizar as de maior volume de busca.

Landing Pages a Criar

Número de páginas cidade × serviço recomendadas pelo sistema que ainda não existem no site. Cada página ausente é uma busca local que a Fox perde para concorrentes.

0–20Lacunas mínimas
20–60Expansão necessária
> 60Grande oportunidade inexplorada
Ação recomendadaUsar os schemas JSON-LD e FAQs gerados em output/5_schemas_jsonld_sugeridos.json para agilizar a publicação das páginas.

Páginas sem Schema.org

Quantidade de páginas sem marcação estruturada (Schema.org tipo AutoRepair ou LocalBusiness). Páginas com schema têm até 20% mais chances de aparecer no Google Maps Pack.

0–10Cobertura de schema adequada
10–50Implementação parcial
> 50Risco de queda no Maps Pack
Ação recomendadaRepassar ao time de desenvolvimento o arquivo output/5_schemas_jsonld_sugeridos.json com os schemas prontos para inserção.

Cadência e Governança

Como usar este painel semanalmente

Roteiro de 10 minutos para a reunião semanal de gestão digital.

1. Verificar SOV (meta: 60%)Cresceu em relação à semana anterior? Se não, quantas LPs foram publicadas? Publicar ao menos 2 LPs por semana para manter crescimento.
2. Alertas de ReviewsAlguma unidade em vermelho (rating < 4,0)? Acionar gerente local para campanha de avaliações antes de perder posição no Maps Pack.
3. Core Web VitalsAlguma página com LCP > 4s? Abrir chamado técnico com prioridade alta — penalização do Google começa imediatamente.
4. Plano de ExpansãoVerificar quantas LPs novas foram publicadas desde a última semana. Meta: reduzir o número de "Ausente" em pelo menos 2 por semana.
